バックエンドはSAMでローカル開発したLambda関数(中身はNode.js)。

IaCにするためAWS CloudFormationでデプロイしています。

Lambda関数一覧

Lambda関数一覧
機能名 メソッド エンドポイント 認証有無 説明
下書き削除 DELETE /item/{itemId}/{itemType}/draft 〇 下書きを削除する処理。
下書きメタデータ一覧取得 GET /item/{itemType}/metadata/draft/list 〇 下書きメタデータの一覧を取得する処理。
アイテム取得 GET /item/{ItemId}/{itemType} アイテム（メタデータ+コンテンツ）を取得する処理。アクセスカウントはこの関数内で実施している。
アイテムメタデータ一覧取得 GET /item/{itemType}/metadata メタデータ一覧を取得する処理。DynamoDBはSQLのような検索に対応していないため、クライアント側にサーチマスターJSONを渡すことで対象アイテムの絞り込み→リクエストとしてはIDを配列で指定することで検索機能を実現している。
下書き公開 PUT /publish/item/{itemId}/{itemType} 〇 下書きを公開する処理。公開前にバリデーションを実施することで壊れたデータが公開されないようにしている。
下書き保存処理 PUT /item/{ItemId}/{itemType} 〇 下書きデータを保存する処理。未完成状態でも保存はできるように、こちらはバリデーションを実施しない。
公開済みメタデータ検索処理 GET /search/item/{itemType}/metadata 公開済みメタデータ検索処理。アイテム種別+並び順を指定することで検索する関数。
問い合わせ送信処理 POST /contact 問い合わせ送信処理。
閲覧数マスター同期処理 PUT /sync/statistics 〇 閲覧数を検索用マスターへ同期する処理。EventBridgeから夜間バッチ処理で実行。

各Lambda関数はリクエストの処理のみを担当し、CORS認証、ルーティング、JWT認証はAPIGatewayが担当しています。
