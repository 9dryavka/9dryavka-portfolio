ブログ用のインフラをAWSで作成しました。

機能ごとに利用したサービスは下記です。

各機能ごとのサービスについて
機能 利用サービス 説明
ドメイン管理 Amazon Route 53 独自ドメインのDNS管理
SSL/TLS証明書 AWS Certificate Manager (ACM) HTTPS証明書の管理
CDN配信 Amazon CloudFront 静的コンテンツの配信
Webアプリケーション保護 AWS WAF Webアプリケーションへの不正アクセス対策
静的コンテンツ保存 Amazon S3 コンテンツJSON・画像などの保存
API公開 Amazon API Gateway APIエンドポイントの公開・ルーティング
ユーザー認証 Amazon Cognito 編集ユーザーの認証・認可
サーバーレス処理 AWS Lambda 公開、検索、問い合わせなどの各種API処理
SSR AWS Lambda（Next.js） クライアント用のスタンドアローン
メタデータ管理 Amazon DynamoDB メタデータ・ビューカウントの保存
メール送信 Amazon SES 問い合わせメールの送信
定期実行 Amazon EventBridge 夜間バッチ（Cron）の起動
